### 2. Decision DNA → Engineering Judgment Graph
**From:** Linear decision storage  
**To:** Interconnected graph

```
Problem Node
    ↓
Evidence Nodes
    ↓
Decision Node ← Similar Decisions
    ↓           Informed by Patterns
Outcome Node
    ↓
Pattern Node ← Related Patterns
    ↓
Counterfactuals (What if?)
```

**This graph becomes the proprietary moat.**

- Year 1: 10,000 nodes
- Year 5: 100,000 nodes
- Year 10: 1,000,000 nodes

### 3. Benchmarks vs Evaluations (Separated)
**Benchmarks (EngineeringNet):**
- Fixed datasets
- 100,000 engineering tasks
- Version comparison
- Measures capability

**Evaluations:**
- Live repositories
- Real customer work
- Measures usefulness

### 4. Intelligence CI Pipeline
**Every commit automatically runs:**
1. Unit tests
2. Integration tests
3. Engineering Olympics
4. Calibration tests
5. Regression detection
6. Performance/cost analysis
7. Generate intelligence report

**If benchmark score drops → merge fails**

### 5. Calibration Benchmark (NEW)
**Question:** If system says 90% confidence, is it right 90% of the time?

**Metrics:**
- Expected Calibration Error (ECE)
- Brier Score
- Calibration Curve

**Critical for autonomous systems.**

### 6. Failure Datasets (NEW)
**Store:**
- Mistakes
- Wrong reasoning
- Bad plans
- Rollbacks
- Near misses

**Often more valuable than success cases.**

### 7. Counterfactuals in Judgment Graph (NEW)
**Not just:** "We chose X and it worked"  
**Also:** "What if we chose Y? Estimated outcome, confidence"

**Enables alternate history reasoning.**

### 8. Research Papers (NEW)
Every major milestone → Internal research paper:
- Hypothesis
- Evaluation
- Results
- Failure cases
- Future work

**Accumulate research archive over years.**

### 9. Intelligence Governance (NEW)
**Before adding ANY new subsystem, answer:**
1. What hypothesis does it test?
2. Which benchmark will improve?
3. Which metric will change?
4. What is the expected effect size?
5. How will we know it failed?
6. Why can't existing subsystems handle this?
7. What is the experiment design?

**If not answered → rejected.**

**Default answer is NO. Architecture is frozen.**
